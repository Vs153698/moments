# @moments/db

Database layer for Moments: Drizzle ORM schema (PostgreSQL + PostGIS), generated SQL migrations, and seed data.

## Layout

```
src/schema/    Drizzle table definitions, grouped by domain:
               identity · categories · moments · participants · media ·
               contributions · route (spec 8) · social · reputation ·
               memory · money · trust · notifications
migrations/    Generated by drizzle-kit — do not hand-edit.
drizzle.config.ts
```

## Commands

```bash
# start dependencies (Postgres+PostGIS, Redis)
docker compose up -d

# from the repo root
pnpm db:migrate   # apply migrations (drizzle-kit migrate)
pnpm --filter @moments/db run generate   # regenerate migrations after schema changes
pnpm db:seed      # seed demo data
```

`DATABASE_URL` defaults to `postgres://moments:moments@localhost:5432/moments` (see `.env.example`).
